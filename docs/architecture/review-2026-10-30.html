架構檢視：規格、實作與重建方向

module seam leak / 壞掉的路徑 deep module 死碼（未接線）

總體狀態

規格與 tasks.md 大量標記 [X]，但多數功能停在「寫了 struct、沒接上呼叫路徑」。#![allow(dead_code)] 出現在 32 個檔案、開發模式假資料使用 PascalCase，兩者共同掩蓋了真實狀態。

A · 下載引擎（spec 001）

只有 happy path 可用。暫停/取消/重試/續傳/代理/排程/並行/速度 皆假或壞。

B · 網站模組（spec 004）

JS 永遠回傳 "{}"；下載不使用模組；安全機制全未接線；每次偵測洩漏 V8 isolate。

C · 前端（spec 002/003）

表格/面板結構完成，但 enum 大小寫不符使狀態、按鈕、主題設定在真實後端下全壞。

D · 跨端接縫

本機 HTTP 允許任何網頁寫任意路徑檔案；Chrome 擴充無法載入；模組 d.ts 與執行期三方不一致。

色條為定性估計：綠 = 可用、黃 = 部分、紅 = 缺漏 / 未接線 / 壞掉。

立即處理（不需等架構決策）

  • 任意檔案寫入：native_messaging/http_server.rs 綁 127.0.0.1:45677、無驗證、allow_any_origin；commands/download.rs:50 以未清理的 filename 做 join（..\ 或絕對路徑可寫到啟動資料夾）。
  • 剪貼簿外洩到區網：http_bridge.rs 綁 0.0.0.0:3030、任意 origin，scripts/run-tauri-dev.sh 預設開啟。
  • enum 大小寫：Rust rename_all="camelCase" 輸出 "downloading"/"light"，TS 比對 'Downloading'/'Light'（約 83 處）→ 狀態顯示、全部暫停/繼續、主題儲存失敗。
  • 30 秒總逾時：download/client.rs:27 reqwest .timeout(30s) 涵蓋整個 body → 超過 30 秒的傳輸必失敗。
  • 重試/續傳寫壞資料：checkpoint 只寫一次、片段檔以 append 重開 → 合併大小不符，任務永遠無法完成。

規格本身的問題

不健全的需求

  • 001 FR-021「±1 byte 容差」：差 1 byte 即損毀；與 merger 的精確檢查互相矛盾。
  • 001 FR-013「預設無上限並行」vs queue 預設 3 vs 實際 1。
  • 004 FR-026「模組對使用者不可見」vs UI 顯示模組名稱與模組管理頁。

MVP 過度範圍

  • FR-039 headless browser、FR-056 關閉 app 後背景服務、FR-033 速度平分到代理。
  • 004 的權限對話框、稽核、自動停權 — 在模組還不能發一個 request 前全部先寫了。

與實作分歧

  • 001 plan.md 寫 libloading 動態庫；實作改 deno_core JS（example-downloader/ 是殘骸）。
  • 003 規格 7 欄，實作 8 欄（多出不存在於 Rust 的 speedPriority）。
  • 媒體驗證（ffmpeg, commit 179ba89）不在任何規格，且未被編譯。

狀態文件不可信

  • specs/004 下 15 份 *_COMPLETE / STATUS / REPORT（約 6k 行）宣稱 Context API 完成。
  • 003 tasks 39/39 完成 — 只對假資料成立。
  • CLAUDE.md 843 行，Feature 003/004 段落重複；其 enum 規則正是大小寫 bug 的來源。

  • locality：每個狀態轉移在同一檔案
  • leverage：commands 變一行
  • 續傳正確性由結構保證
  • test 經 interface + 本機 fixture server
  • 刪除 queue / merger / scheduler 迴圈
  • progress 事件節流至 ~4Hz

Top recommendation

1. DownloadManager

下載是產品本身；網站模組、擴充、前端同步、設定全部都要接到它。目前狀態有三個擁有者、續傳會寫壞資料，任何其他改善都建在這個不穩的地基上。先完成 Phase 0 熱修與 Phase 1 刪除（成本低、立即降低風險），再以 DownloadManager + PartFile 作為第一個重建的 deep module，並用本機 fixture server 經其 interface 測試。
