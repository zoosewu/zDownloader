## B：網站模組後端（spec 004）

### 實際呼叫路徑 ✔

`AddDownloadForm.tsx:175` → `detect_url_module`（`clipboard.rs:65`）→ `find_modules_directory()` → `ModuleRegistry::with_path().scan_and_register()` → 對**每個**模組目錄：

1. 讀 manifest
2. 用字串替換去掉 `export`（`loader.rs:89-98`）
3. `JsRuntime::new(Default)`，無 heap 限制
4. 執行 sandbox script
5. **執行未受信任的頂層程式碼**
6. `new Class()`

接著用 glob 比對 `urlPatterns`（`registry.rs:268-293`），然後 drop registry，`JsRuntimeHandle::drop` 對每個 isolate 做 **`mem::forget`**（`js_runtime.rs:134-145`）。

之後 `create_download_with_path` 使用空的 registry（`download.rs:83`），建立一般下載。`extractDownloadInfo` 從未在真實路徑上被呼叫。

路徑上的強制點：網路 allowlist、SSRF、速率限制、稽核、CPU 逾時、heap 上限 **全部不存在**。
